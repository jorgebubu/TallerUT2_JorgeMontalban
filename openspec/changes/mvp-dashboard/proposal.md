# Propuesta: Dashboard Web MotorShield Taller - JM

## Por qué (Objetivo)
Necesitamos una interfaz web rápida, visual y segura para que el equipo TIC del taller consulte las incidencias procesadas en `datos_tickets.json`, filtre por urgencia, cambie estados y registre nuevos tickets con protección automática de datos personales (RGPD).

## Qué se construye (Alcance)
Un Dashboard SPA (Single Page Application) en `index.html` y `app.js` usando TailwindCSS y `localStorage`.
